# ProofBox — Warranty & Receipt Vault

A full-stack MERN application for organizing product purchases, archiving digital receipts and invoices, authoritatively calculating warranty expiration timelines, and delivering timely expiration intelligence before coverage lapses.

---
## ProofBox is an individual personal application that enables the user to handle purchase records, keep receipts and warranty information.

It has the following key characteristics:
1. Product Registry: Keep product name, category, seller, price and purchase date.
Receipt Vault: Add and save images and PDF receipts.
3. Warranty Tracking: Automatically calculate warranty expiry dates.
Expiring Soon Radar: Show warranties about to expire in 30 days.
5. Friendly User Design: Offer an uncluttered, straightforward interface, with easy navigation and product views.
---
## 2. Technology Stack
Stack: React, Node.js, Express.js, MongoDB.
